# Jurisdiction profiles

Rules 3.2, 6.5, 6.6 and 6.7 turn on the governing jurisdiction. A profile
answers those four questions once for a jurisdiction, with citations, so that
the rules do not have to be qualified in place.

`TEMPLATE.md` is the structure. Copy it to `<jurisdiction>.md` and fill it in.

**No profile has been compiled yet.** The template deliberately ships empty.
Filling one in requires reading that jurisdiction's drafting manual, code
provisions on headings, retroactivity and severability, and the decisions
construing them. That is legal research, and an uncited answer in a profile is
worse than a blank one, because a reader will rely on it.

`UNVERIFIED` is a legitimate value. Use it.

The licence permits jurisdiction-specific adaptations. A profile compiled by
someone else is an adaptation and carries the same licence (CC BY-NC-SA 4.0).

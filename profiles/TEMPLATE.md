# Jurisdiction profile — template

Four rules in MLP-1 turn on the governing jurisdiction. Rather than qualifying
each rule in place, a profile states the jurisdiction's answers once, and a
writer working in that jurisdiction reads the profile alongside the standard.

**A profile is a research artifact, not a drafting exercise.** Every answer
needs a citation to a code section, a court rule, a drafting manual, or a
decision. An uncited answer is worse than no profile, because a reader will
rely on it.

**Leave an answer blank rather than guessing.** `UNVERIFIED` is a legitimate
value and it is the correct one until someone checks. A profile with four
verified answers and three blanks is useful. A profile with seven plausible
answers is a liability.

Copy this file to `profiles/<jurisdiction>.md` and fill it in.

## 1. The operator — Rule 3.2

MLP-1 says do not write *shall*. That rule **yields to a governing drafting
manual**, and most state legislatures still teach *shall* as the mandatory
operator.

| Question | Answer | Authority |
|---|---|---|
| Is there a legislative drafting manual? | | |
| Does it prescribe a mandatory operator? Which? | | |
| Does it prescribe a permissive operator? | | |
| Does it address *shall not* versus *may not*? | | |
| Is there a separate manual for administrative rules? | | |
| Is there a court-rule drafting standard? | | |
| Does a code section define *shall* or *may*? | | |

**Consequence for a drafter.** If the manual prescribes *shall*, Rule 3.2 does
not apply to text destined for that office. Follow the manual and record that
you did.

**Consequence for a restatement.** None. The manual governs drafting, not
restating. A source's *shall* is still mapped under Rule 10.7, and a contested
construction is still left unmapped.

## 2. Section headings — Rule 6.5

Whether a heading may be considered in construing a provision.

| Question | Answer | Authority |
|---|---|---|
| Is there a code provision on headings? | | |
| May a court consider a heading when construing text? | | |
| Are headings enacted, or added by a reviser? | | |
| Does the answer differ between statutes and court rules? | | |

Record the answer as one of: **construable**, **not construable**,
**construable only if enacted**, or `UNVERIFIED`.

**Consequence.** A restatement must not import content from a heading into the
body where headings are not construable, and must not discard a heading's
content where they are. Rule 6.5 forbids assuming either answer.

## 3. Retroactivity on silence — Rule 6.6

What a silent statute does, in this jurisdiction.

| Question | Answer | Authority |
|---|---|---|
| Is there a general code provision on retroactivity? | | |
| Does it bar retroactive operation unless expressly stated? | | |
| Or is it a presumption that contrary intent can defeat? | | |
| Do procedural and substantive provisions differ? | | |
| Is there a distinct rule for court rules? | | |

Record as: **express-statement required**, **rebuttable presumption**,
**no general provision**, or `UNVERIFIED`.

**Consequence.** Where a source is silent, the restatement says it is silent
and cites the governing default. It never states the default as though the
source had stated it. Rule 10.4 controls.

## 4. Severability — Rule 6.7

| Question | Answer | Authority |
|---|---|---|
| Is there a general severability provision in the code? | | |
| What is its scope — whole code, a title, enactments after a date? | | |
| Does it apply to court rules? To administrative rules? | | |
| Does a decision limit it? | | |

Record as: **general provision applies**, **applies with limits**, **no general
provision**, or `UNVERIFIED`.

**Consequence for a drafter.** Where a general provision applies, a drafter may
rely on it and say nothing. Where none applies, silence is a defect.

**Consequence for a restatement.** Where the source is silent and a code
provision supplies the answer, cite the code provision. Do not present the
answer as the source's own.

## 5. Anything else this jurisdiction does differently

Free text. Record any practice that changes how a rule in MLP-1 applies here —
a citation format the courts require, a mandated plain-language standard, a
statutory construction act that settles a question MLP-1 leaves open.

Each entry needs a citation.

## How a profile is used

1. The writer reads the profile before drafting or restating in the
   jurisdiction.
2. Where a profile answer is `UNVERIFIED`, the writer treats the question as
   open and applies Rule 10.4 — state the uncertainty rather than resolving it.
3. A profile never overrides Section 10. It answers questions about the
   governing law. It never licenses supplying an answer the source withholds.

**A profile is not authority.** It is a compiled finding-aid pointing at
authority. A restatement cites the underlying code section or decision, never
the profile.
